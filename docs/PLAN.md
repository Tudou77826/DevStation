# DevStation MVP 实施计划

MVP 要完成以下本地研发闭环：

```text
任务 → Git 项目 → Agent 会话 → 本地运行 → 状态恢复 → Diff 评审 → 人工提交
```

SSH、远程运行、worktree、外部任务平台、自动提交和可视化工作流不在 MVP 范围内。

## 已完成基础

阶段 0～2.5 已完成：Electron/React 框架、Codex 风格布局、任务/项目/会话 SQLite 持久化、基础 Shell/Codex PTY，以及测试与质量门禁。

当前实现边界见[当前状态](./STATUS.md)，代码位置见[代码地图](./CODE_MAP.md)。

## M3：终端与 Agent 可用

目标：从任务上下文稳定运行 CLI Agent，并保留可恢复的终端入口。

工作：

- `[L3]` 将终端绑定 Task、Project 和工作目录。
- `[L4]` 支持多个终端和基础分屏。
- `[L4]` 保存终端元数据与有限滚动记录。
- `[L4]` 定义 Agent 适配接口：启动、环境、Hook、Session ID、恢复命令。
- `[L3]` 接入首个 CLI Agent，并区分正常退出和异常退出。
- `[L4]` 补充 TerminalPane 跨进程和异常生命周期测试。

验收：

- 能从任务关联项目目录启动 Agent。
- 多个终端互不干扰，窗口销毁后资源正确清理。
- 应用重启后能恢复终端入口和必要记录，但不承诺恢复已退出的操作系统进程。

## M4：状态跟踪与会话恢复

目标：用户能看到 Agent 状态，并通过 Agent 原生命令恢复历史会话。

工作：

- `[L5]` 接收并标准化 Agent Hook 事件。
- `[L4]` 保存 Agent Session ID，并关联 Task、Project 和工作会话。
- `[L3]` 展示运行中、等待用户、完成和失败状态。
- `[L2]` 提供会话搜索、最近访问和侧边栏状态。
- `[L4]` 调用 Agent 原生恢复命令；Hook 缺失时保持终端可用。

验收：

- Agent 状态能及时显示。
- 应用能找到任务对应的 Agent Session。
- 历史工作会话可以恢复；DevStation 不自行重建 Agent 内部对话状态。

## M5：Git 与 Diff 评审

目标：用户能发现 Agent 产生的变更并完成本地评审。

工作：

- `[L2]` 读取当前分支、工作区状态和变更文件。
- `[L3]` 展示文本文件 Diff。
- `[L3]` 支持本地行级评论的新增、修改、删除和持久化。
- `[L2]` 在右侧面板和状态区展示 Git 摘要。
- `[L3]` 处理非 Git 项目、脏仓库、大文件和二进制文件。

验收：

- Agent 修改后能自动发现文件变更。
- 用户可以查看 Diff 并保存本地评论。
- 应用重启后评审状态仍然存在。

## M6：链路联调与内部发布

目标：完整链路可供内部开发人员稳定试用。

工作：

- `[L4]` 串联任务、项目、会话、终端、Hook 和 Diff。
- `[L3]` 补齐错误提示、空态、恢复提示和诊断导出。
- `[L4]` 验证 Electron 安全配置、Preload 白名单和 IPC 参数。
- `[L4]` 建立 Windows 干净安装、升级、卸载和签名验证。
- `[L3]` 执行完整链路和异常恢复测试。

验收：

- 新机器可安装并完成目标闭环。
- 应用异常退出后任务与会话关联不丢失。
- Agent、Git 或数据库失败时提供可执行的错误提示。
- `verify:release` 覆盖安装升级、SBOM、签名和产物一致性。

## 顺序与裁剪

```text
M3 Agent 可用 → M4 状态可见 → M5 变更可评审 → M6 内部发布
```

不得裁剪：项目目录启动 Agent、Hook 状态、会话恢复入口、Git 变更和文件 Diff。

进度不足时依次裁剪：工作流继续占位、分屏固定为两栏、行级评论只保留新增/删除、文件页只读、首版只支持一个 CLI Agent。

## 完成定义

满足以下条件后 MVP 可进入内部试用：

- 用户能创建任务、关联本地 Git 项目并启动 CLI Agent。
- 用户能看到 Agent 状态，并在重启后恢复会话入口。
- 用户能查看文件 Diff 并保存本地评审评论。
- 主链路不依赖 SSH、worktree 或外部任务平台。
- Windows 安装、升级、卸载和安全门禁通过。
